A one-page newspaper front page summing up Wednesday 18 November 2026: 34 real stories from every continent, a hero story on APEC opening in Shenzhen and the Quad meeting in Manila, a world map with numbered story markers, and a day-in-numbers panel. Drawn entirely by `main.py` in pure Python 3.13 stdlib — a hand-rolled PNG encoder, a 5x7 bitmap font, and polygon continents. No network, no dependencies; two runs write byte-identical PNGs.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
